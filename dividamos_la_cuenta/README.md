# dividamos_la_cuenta

App Móvil de Liquidación de Gastos P2P (Split-Bill)

## Instalación

1. Instala Node.js y Expo CLI:
   ```bash
   npm install -g expo-cli
   ```
2. Instala dependencias:
   ```bash
   npm install
   ```
3. Inicia el proyecto:
   ```bash
   npm start
   ```

## Estructura
- `models/`: Modelos de datos (Realm)
- `services/`: Servicios (API, almacenamiento seguro)
- `screens/`: Pantallas principales
- `components/`: Componentes reutilizables

## Funcionalidades MVP
- Ingreso y división flexible de gastos
- Selección de participantes desde contactos
- Algoritmo de minimización de transacciones
- Solicitud de pago vía WhatsApp con Alias/CVU seguro
